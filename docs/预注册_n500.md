# n=500 确认阶段：预注册（先写，后跑）

写入时间：2026-10-18，在 n=500 的任何结果产生之前。

## 1. 目的

n=100 的确认性实验已经得到：真实 role 先验的 MB 恢复 F1 显著高于同分布随机先验
（CHILD +0.0120、INSURANCE +0.0299，50 次配对，单侧 p<0.0001；第 21–50 次独立复现）。

本阶段只回答一个问题：**这个收益在 n=500 时是否仍然存在。**
不回答"先验对更多网络是否普遍有效"——那属于探索层，见第 3 节。

## 2. 与 n=100 阶段的关系

- 冻结参数：γ=2.0、四组变体、5 次随机打乱、三道关卡、主要终点、检验方向。
- 不改先验（同一份 Qwen3-8B-AWQ role 版多数投票结果）。
- 不覆盖任何 n=100 的文件；新结果使用 tag `confirm_n500_g2`。

## 3. 设计

| 层次 | 网络 | 重复 | 用途 |
|---|---|---|---|
| 确认层 | CHILD、INSURANCE | 50 | 与 n=100 同口径，做"通过/不通过"判定 |
| 探索层 | ASIA、ALARM、HAILFINDER | 待定时 | 只报效应量与区间，不做判定 |

四组变体与 n=100 完全一致：baseline / prior-hard / prior-soft / random-soft。

## 4. 主要终点与统计

- 主要终点：D = F1(prior-soft) − F1(random-soft)，逐次配对。
- 单侧 α=0.05（方向已事先确定）；报告双侧 95% CI 与符号计数。
- 以 t 检验为主，Wilcoxon 为稳健性对照。
- 次要指标（precision、recall、父/子召回、配偶召回）只作解释。

## 5. 关卡（任一失败即停止，不进入比较）

1. γ=0 与 baseline 逐位一致（含搜索轨迹）。
2. 硬约束确实排除了变量，或该网络没有可排除项。
3. 软约束不排除任何变量。
4. 同一次重复内四个变体的 sample_hash 与 prior_values_hash 一致（配对同源）。

## 6. 判读规则（事先写死）

- **A**：D 的均值 > 0 且 95% CI 不含 0 → 收益在 n=500 下保持。
- **B**：D 的均值 > 0 但 CI 跨 0 → 证据不足；报告区间宽度，不追加重复次数去追显著。
- **C**：D 的均值 ≤ 0 → 小样本收益未能延续；检查先验是否仍改变搜索决策，再讨论原因。

无论落在哪一档，都同时报告 soft − baseline 与 hard − baseline，避免只看一个对照。

## 7. 明确不做的事

- 不因为 n=500 结果不显著而回头调 γ 或换网络。
- 不把探索层的结果写成"方法有效"的证据。
- 不用 n=500 的结果覆盖或重写 n=100 的报告。

