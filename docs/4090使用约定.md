# 4090 使用约定

按《选题 1–5 的学习资料与 12 周计划》的要求整理。
本机是 RTX 3060 Laptop（6144 MiB），**不是** 4090，
所以下面的约定既约束远程 4090，也说明本机能做与不能做什么。

## 谁能用卡

| 选题 | 用卡方式 | 建议时段 |
|---|---|---|
| 1 | 只做推理，单次几分钟到几十分钟 | 白天，随用随跑 |
| 2、3 | 少量语言模型判断，其余在 CPU | 白天；也可以用免费的 T4，不占 4090 |
| 4 | 向量模型加少量语言模型判断，主要吃内存 | 白天；表连接和训练轻量模型在 CPU 上 |
| 5 | 反复微调，单次可达数小时 | 夜间和周末整段占用 |

选题二属于"用卡很低"的一档：**4090 上只跑语言模型判断，其余全部在 CPU 上完成。**

## 四条约定

1. **共享一张排期表。** 长于一小时的任务提前登记；跑之前先用 `nvidia-smi` 看一眼有没有人在用。
2. **所有语言模型的输入输出都缓存到磁盘，同样的输入不算第二遍。**
   本项目已经实现：`data/<NET>/llm_cache/` + `PROMPT_VERSION` 版本号。
3. **调试用小数据、小模型，在本机或免费 T4 上完成；4090 只跑正式实验。**
4. **长任务放在 tmux 里运行，日志落盘，并定期保存检查点，被打断后能续跑。**
   本项目的推理脚本一次生成就落一次盘，中断后重跑自动跳过已完成部分。

## 本机能做什么、不能做什么

| 事项 | 本机（3060 6GB） | 4090 |
|---|---|---|
| 4B 模型 4bit 推理 | 可以，真实名模式约 0.6 次/秒，匿名模式约 0.2 次/秒 | 可以，且可上 8B |
| 8B 模型 8bit 推理 | 不行（显存不足，CPU offload 慢到不可用） | 可以 |
| **vLLM** | **不行**：原生 Windows 没有任何可安装的 vLLM 发行版（`pip download vllm` 返回 `No matching distribution found`）。要用 vLLM 必须 WSL2 或 Linux | 可以，建议用 vLLM 跑批量推理 |
| 马尔可夫毯发现 / 融合实验 | 可以，纯 CPU | 不需要 |
| R / bnlearn 导出 DAG | 没有 R | 需要时在实验室 Linux 机器上用 R 导出 |
