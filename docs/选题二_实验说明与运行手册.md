本文档记录代码结构、运行方式、当前进度，以及实验过程中踩到的坑。

| 11–12 | TableShift 全部任务：普通特征选择 / 纯数据因果特征选择 / 我们的方法 | 主结果表、阶段报告 |

验证性实验：

1. **bnlearn 部分**：小样本时加入语言模型先验能否提高马尔可夫毯恢复质量；变量名匿名后提升是否消失。
2. **TableShift 部分**：3 个任务上，因果特征选择与按预测力选择的特征，从分布内到分布外的性能下降幅度比较。

通过标准：样本量 ≤ 500 时，先验在至少一半的网络上提高了恢复 F1，且匿名后提升基本消失；
3 个 TableShift 任务中至少 2 个，因果特征的分布外性能下降更小。

## 3. 运行方式

### 3.1 语言模型先验（需要显卡，用 llm_causal_fs 环境）

```powershell
cd E:\Causal-LLM
& 'D:\Anaconda\envs\llm_causal_fs\python.exe' scripts\run_llm_prior.py `
    --network CHILD --mode both --runs 5 --batch-size 12
```

* `--mode both` 会依次跑真实名与匿名两种模式，便于做消融。
* 每次生成都写进 `data/<NET>/llm_cache/<mode>.jsonl`，同一输入永不重复计算；
  中断后重跑会自动跳过已完成部分。
* 改动 Prompt 后要把 `prompt.py` 里的 `PROMPT_VERSION` 加一，
  旧版本缓存会自动失效，不需要手工删文件。

各网络规模与预计耗时（本机 RTX 3060 Laptop 6GB，Qwen3-4B-Instruct-2507 4bit，
真实名模式约 0.6 次/秒，匿名模式约 0.2 次/秒）：

### 3.2 先验评测与融合实验（纯 CPU，用 base 环境）

```powershell

python scripts\run_fusion_experiment.py --networks ASIA,CHILD --sizes 100,500 --repeats 5 --mode real

```

融合实验的五个变体：

| 变体 | beta | gamma | 先验 | 含义 |
|---|---|---|---|---|
| baseline | 0 | 0 | 无 | 纯数据的经典算法 |
| prior-thresh | 1.0 | 0 | 真实名 | 先验调节条件独立检验阈值 |
| prior-search | 0 | 1.5 | 真实名 | 先验作为搜索优先级 |
| prior-thresh+search | 1.0 | 1.5 | 真实名 | 两者同时 |
| random-thresh | 1.0 | 0 | 随机打乱 | 对照：证明提升不是随便扰动就能拿到 |

## 4. 已经踩到的坑（重要）

1. **旧 Prompt 只定义了 11 个变量。**
   原 `prompt.py` 里只有 ALARM 的 11 个变量写了解释，其余 26 个变量退化成
   "exact meaning is not provided"。模型由此把医学缩写猜错，
   例如把 `CVP` 当成"本量利分析（Cost-Volume-Profit）"。
   现已补齐 5 个网络共 148 个变量的含义。

2. **置信度恒为 0。**
   旧 Prompt 的 JSON 示例里字面写着 `"confidence": 0.0`，模型直接照抄，
   导致所有先验的置信度都是 0。现已把示例换成说明性格式并明确要求给出 0–1 的数值。

3. **模型会自己虚构中间变量。**
   只有"直接相连"这个要求时，模型会把 `asia → tub` 判成"通过中间机制"，输出"无边"。
   加入"不要虚构中间变量"的规则后，这种漏判消失，但出现了相反倾向：
   对存在间接通路的变量对（如 smoke–xray）也判成直接相连，
   表现为**召回高、精确率低**（ASIA 上 edge recall = 1.00，precision ≈ 0.40）。
   这是本次实验的一个真实发现，报告里要写清楚。

4. **方向判断反而很准。**
   在模型真正给出方向的真实边上，ASIA 的方向准确率是 7/7。
   也就是说：模型"敢说方向"的时候是可信的，
   它的弱点在于判断"这两个变量到底有没有直接边"。

### 已完成的关键结果（ASIA 试点，n=100 / n=500，各重复 5 次）

| 设定 | IAMB | HITON-MB |
|---|---|---|
| baseline（n=100） | 0.5029 | 0.5070 |
| 真实名先验 · 阈值+搜索（n=100） | 0.5379 | **0.5720** |
| 随机先验 · 阈值（n=100，对照） | 0.4995 | 0.4636 |
| 匿名先验 · 阈值（n=100，消融） | 0.4895 | 0.5052 |
| baseline（n=500） | 0.6864 | 0.6006 |
| 真实名先验 · 阈值（n=500） | 0.6898 | 0.5806 |

结论要点：

* n=100 时真实名先验稳定带来提升（HITON-MB +6.5 个百分点），n=500 时收益消失。
* 随机先验在同样强度下反而变差，说明提升来自先验的具体内容。
* 匿名后先验退化成常数（28 对全判"无边"，置信度 0.915），提升随之消失。
* 语言模型的邻接判断偏松（召回 1.00、精确率 0.40），但方向判断可靠（7/7）。
