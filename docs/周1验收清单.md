# 周 1 验收清单（环境与规范）

文档对周 1 的要求：环境与规范 —— Git、conda、远程用 4090（ssh、tmux、nvidia-smi）；
统一实验规范（固定随机种子、配置文件、日志落盘、结果表由脚本生成）；
用 transformers 和 vLLM 各跑通一个 4B–8B 的开源模型，并让它按指定的 JSON 格式输出。

验收产出：个人分支、README、一段结构化输出的结果、4090 使用约定。

## 产出对照

| 产出 | 状态 | 在哪里 |
|---|---|---|
| 个人分支 | 待你执行一次 | `scripts/init_git.ps1`（沙箱里 .git 只读，必须在你自己的终端跑） |
| README | 完成 | `README.md` |
| 一段结构化输出的结果 | 完成 | `data/ASIA/ASIA_LLM_prior_real.json`（每对 5 次采样，含原始输出、投票结果、一致性） |
| 4090 使用约定 | 完成 | `docs/4090使用约定.md` |

## 规范对照

| 要求 | 落实方式 |
|---|---|
| Git | 仓库已初始化；首次提交脚本 `scripts/init_git.ps1`；`.gitignore` 已排除 `__pycache__`、`logs/*.log`、`data/*/llm_cache/` |
| conda | 两个环境分工写进 README：base 做 CPU 分析，`llm_causal_fs` 做 GPU 推理 |
| 远程用 4090 | 本机是 3060 6GB，远程访问需要你自己配 ssh/tmux；约定写在 `docs/4090使用约定.md` |
| 固定随机种子 | 推理种子 = `base_seed + 批次起点`；抽样种子 = `seed + 重复编号`；都在 `configs/` 里 |
| 配置文件 | `configs/llm_prior.json`、`configs/mb_discovery.json`；脚本支持「配置做默认值 + 命令行覆盖」 |
| 日志落盘 | `src/common/run_log.py`；每次运行在 `logs/` 生成日志，头部含命令行、配置、git 提交、环境、显卡 |
| 结果表由脚本生成 | `results/` 下所有 CSV 均可由 `run_fusion_experiment.py` / `eval_llm_prior.py` 一条命令重跑 |

## 模型跑通情况

| 要求 | 状态 | 说明 |
|---|---|---|
| transformers 跑通 4B–8B 开源模型 | 完成 | `llm_causal_fs` 环境，torch 2.5.1+cu121；本机 6GB 显存实际使用 Qwen3-4B-Instruct-2507 4bit |
| 按指定 JSON 格式输出 | 完成 | Prompt 强制输出 `direct_edge / relation / confidence / reason`；解析器容错（去代码围栏、截取花括号） |
| vLLM 跑通 | **未完成，且本机不可行** | `pip download vllm` 在原生 Windows 返回 `No matching distribution found`（vLLM 只提供 Linux 发行版）。要用 vLLM 需要 WSL2 或 Linux 的 4090 |

## 还需要你自己做的三件事

1. 在你的终端执行 `powershell -ExecutionPolicy Bypass -File scripts\init_git.ps1` 完成首次提交并切到个人分支。
2. 有远程仓库的话加上 `git remote add origin <地址>` 并 `git push`。
3. vLLM 那条要么用 WSL2，要么在 Linux 机器上补跑一次；本机无法完成。
